# 目的
Qwen3-TTS（オープンウェイト版）の3種類のモデルが動くかを最短で検証する。
主目的はボイスクローン。UIは作らない。CLIスクリプトのみ。

# 環境
- Linux（WSL2）、RTX 4090（24GB）
- Python仮想環境はuvで作成
- まず nvidia-smi でドライバ・CUDAバージョンを確認し、結果を報告すること

# 前提調査（実装前に必ず行う）
- 公式リポジトリ https://github.com/QwenLM/Qwen3-TTS のREADMEと、
  Hugging Faceの各モデルカード（Qwen/Qwen3-TTS-12Hz-1.7B-Base、
  -1.7B-VoiceDesign、-1.7B-CustomVoice）を読み、各モデルの正しい呼び出し方
  （引数、参照音声の書き起こしの扱い、言語指定、話者名・指示文の書き方、
  生成パラメータ）を確認してから実装する
- 記憶や推測でAPIを書かないこと

# 実装内容
1. `qwen-tts` パッケージを導入。flash-attnはまず入れずに動かし、
   動いたあとで導入を試す（失敗したらSDPAのままで可）
2. 共通の計測ユーティリティ：モデルロード時間、合成時間、
   生成音声の長さ、RTF（合成時間/音声長）、ピークVRAMを表示
3. `spike_clone.py`（最優先）
   - 引数：参照音声パス、参照音声の書き起こし、合成テキスト、言語、
     モデルサイズ（1.7B / 0.6B、デフォルト1.7B）
   - 出力：outputs/ にWAV保存
4. `spike_design.py`：声の説明文＋合成テキスト → WAV
5. `spike_custom.py`：利用可能なプリセット話者一覧を表示し、
   話者＋（対応していれば）スタイル指示＋合成テキスト → WAV
6. `spike_vram.py`：1.7Bの3モデルを順にロードし、
   すべて同時にロードした状態のVRAM使用量を計測

# 検証ケース
参照音声は samples/ に私の声を用意する（日本語・英語各1本、5〜10秒、書き起こし付き）。
- クローン：日本語参照→日本語、英語参照→英語、日本語参照→英語
- クローン：0.6Bでも同じケースを実行して比較
- VoiceDesign：日本語・英語で各1〜2パターン
- CustomVoice：日本語・英語で各1話者
